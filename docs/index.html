A Mac app for Claude Code

Find that conversation you already had.

⌕

Claude Code already writes down every session you have. Déjà Vu reads those logs and makes your conversations searchable across every terminal, every repo, in one window.

$ brew trust xsreality/tap $ brew install xsreality/tap/claude-deja-vu
macOS 14+ · free · MIT
trust is Homebrew’s approval step for a third-party tap

what it does

Search what was said, not what it was called

One box searches the full text of every message in every conversation. Results show the match in context, so you can tell which one is the one you want, and the same term surfaces work from repos you'd forgotten touched it.

Or find it by the file you were in

Start a search with file: and paths replace prose. Completions drop down as you type, and the results are the conversations where Claude actually read or edited that file, so it finds work, not directory listings.

Let Claude group related work

Cross-reference asks Claude to read your recent conversations and sort them into topics. Topics span projects, so one auth migration pulls together three repos. Each conversation also gets a one-line summary of what it was really about, and an activity strip answers "which week was that?" before you start scrolling.

the smaller things

Resume

One click copies the cd … && claude --resume … for the conversation you're reading. Paste it and carry on.

Live

The open transcript keeps updating while the conversation continues in your terminal.

Readable

Transcripts render markdown (headings, tables, code blocks) instead of a wall of raw log text.

Receipts

Each transcript shows the model, how long it ran, and the files and tools it touched.

One repo

Narrow the whole view (list, search and activity) down to a single project.

Jump to it

Open a search result and the transcript scrolls to the first hit, every occurrence highlighted.

what it does with your data

Local by default. Verifiable by design.

  • It only reads ~/.claude/projects. It never edits or deletes a log.
  • Browsing and searching make no network calls at all.
  • It writes exactly one file, for its own cache.
  • Cross-reference is the one thing that leaves your Mac: it runs the claude CLI you already have, and only when you click the button.
  • No third-party dependencies. Swift and Apple frameworks, nothing else to audit.
